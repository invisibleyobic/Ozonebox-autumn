# OZONEBOX - осенняя коробка (концепция)

Начни с `HANDOFF.md`: там решения владельца, состояние и следующие шаги. План с фазами - `docs/plan.md`, промпты - `PROMPTS.md`.

- Отвечай по-русски, в файлах дефис вместо длинного тире.
- Картинки генерирует Claude через коннектор Higgsfield; видео - владелец сам.
- Тексты - по скилу `slopotron`, без медицинских обещаний («лечит», сроки результата) и без выдуманных фактов.
- Надписи не вшиваются в картинки и видео: только HTML поверх (кроме настоящих этикеток на флаконах).
- Секреты и ключи в репозиторий не кладём.
