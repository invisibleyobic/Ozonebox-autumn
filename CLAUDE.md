## Проверка git email (каждый раз в начале работы на компьютере владельца)

Владелец скрыл почту на GitHub и включил «Block command line pushes that expose my email». Первым делом выполни `git config --global user.email`:
- если это `73368572+invisibleyobic@users.noreply.github.com` - всё хорошо, молчи;
- если другой адрес или пусто - сразу скажи владельцу «на этом компьютере git email не настроен, пуши будут отклоняться» и предложи выставить: `git config --global user.email "73368572+invisibleyobic@users.noreply.github.com"`. Выставляй после его «да».
- в облачной сессии Claude Code (адрес `noreply@anthropic.com`) ничего не меняй.
