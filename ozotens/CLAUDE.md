# ОЗОТЭНС - навигация по проекту

Сайт метода ОЗОТЭНС: карманный прибор ТЭНС + озонсодержащий крем OZOTENS 30% + фигурный электрод, для людей с болью в спине, шее и суставах. Отдельный проект, с OzoneBox не смешиваем.

## Структура

```
ozotens/
├── CLAUDE.md          ← этот файл
├── ВОПРОСЫ.md         ← единый список открытых вопросов
├── .starter/          ← общий процесс стартера (не править руками)
├── idea/              ← замысел (эфир 2): superidea → pitch
├── architecture/      ← чертёж (эфир 3): правила, шаги 1-10
├── design/            ← дизайн (эфир 5): рефы, бриф, система, варианты, суд
├── mockups/           ← макеты-имитации, не код продукта
├── plans/             ← планы отдельных задач
├── retrospectives/    ← рефлексии после сессий
└── prompts/           ← библиотека промптов
```

## Порядок источников при конфликте

1) прямое решение владельца в чате; 2) `architecture/00-правила-проекта.md`; 3) чертёж `architecture/README.md`; 4) этот файл; 5) `.starter/workflow.md`.

- Замысел - `idea/`, начинать с `idea/pitch.md`.
- Перед любой работой с внешним видом - `design/README.md`.
- Отвечай по-русски, в файлах дефис вместо длинного тире.
- Картинки генерирует Claude через Higgsfield; видео - владелец.
- Тексты - по скилу `slopotron`, без медицинских обещаний и без выдуманных фактов.
- Надписи не вшиваются в картинки и видео: только HTML поверх.
- Секреты и ключи в репозиторий не кладём.
