# Дизайн-система ОЗОТЭНС

Закон для любого внешнего вида сайта. Читается перед любой работой с интерфейсом (маршрут - `README.md`). Своя система, с OzoneBox не пересекается.

**Источник значений - блок `:root` в `mockups/v2/index.html`** (потом переедет в код продукта). Здесь роли и правила.

## 1. Палитра ролями

Страница тёмная намеренно: один источник света на темноте - главный приём (`refs/analysis.md`, Superpower). Светлой темы нет.

| Роль | Переменная | Значение | Где |
|---|---|---|---|
| Ночь (фон) | `--night` | `#07090c` | весь сайт |
| Поверхность | `--panel` | `#0f141a` | панели, квиз, карточки документов |
| Линия | `--line` | `rgba(255,255,255,.1)` | рамки, разделители |
| Текст | `--ink` | `#eef2f4` | заголовки, основной текст |
| Текст приглушённый | `--ink-soft` | `#a3afb7` | пояснения |
| **Боль** | `--pain` | `#ff5a36` | только точка боли, «болит»-моменты, противопоказания |
| Тепло | `--ember` | `#ffb04a` | ореол боли, переход |
| **Озон (акцент, один)** | `--ozone` | `#3d7bff` | главная кнопка, импульс, ссылки, фокус |
| Свечение озона | `--glow` | `#8db8ff` | кольца импульса, экран прибора |

Сюжет цвета: сверху тепло и боль, к низу страница остывает в синий. Фон страницы сам меняет температуру при прокрутке.

## 2. Шрифты

- **Unbounded** 600 - заголовки. Широкий, «приборный», читается крупно.
- **Onest** 400/500 - текст. Кириллица без компромиссов.
- **JetBrains Mono** - только показания прибора, коды документов, время в «дне».
- Текст для чтения не меньше 18 px (аудитория 35-55+). Шкала: 13 / 16 / 18 / 22 / 32 / 48 / 72+.

## 3. Геометрия

- Скругление: панели 24px, кнопки - капсула, кадры 18px.
- Линии 1px `--line`. Теней нет, есть свечение (glow) только у озона и боли.
- Зона нажатия от 48 × 48 px.

## 4. Компоненты

| Компонент | Покой | Наведение | Фокус |
|---|---|---|---|
| Кнопка главная | фон `--ozone`, текст белый, капсула 56px | свечение `--glow` | кольцо 3px `--glow` |
| Кнопка вторая | контур `rgba(255,255,255,.35)`, текст `--ink` | контур `--ink` | кольцо 3px `--glow` |
| Кадр (место под видео/фото) | тёмный, медленно «дышащий» градиент, красная точка REC, описание кадра | - | - |
| Чип квиза | контур, текст `--ink` | контур `--ink` | выбран: фон `--ozone` |

## 5. Анимации - живые фоны

1. **Фон страницы (WebGL):** мягкий шум-свет, температура от `--ember` к `--ozone` по прокрутке.
2. **Позвоночник (canvas):** точки-позвонки, точка боли на пояснице, кольца импульса расходятся с частотой прибора.
3. **Кадры:** медленно дышащий градиент внутри рамки.

Не больше двух движений в одном экране. Кривая `cubic-bezier(.2,.8,.2,1)`. `prefers-reduced-motion` - один статичный кадр, без анимации. Страница читается без JavaScript и WebGL.

## 6. ЗАПРЕЩЕНО

1. **Текст внутри видео и картинок.** Только HTML поверх. Причина: правка, индексация, закон.
2. **Медицинские обещания** в любом тексте интерфейса. Причина: закон о рекламе медицинских изделий (`architecture/00-правила-проекта.md`).
3. **Анимация «вылечили»**: точка боли не гаснет от ползунка прибора. Остывание цвета - сюжет прокрутки, а не демонстрация эффекта. Причина: то же.
4. **Второй акцент.** `--pain` - не акцент, кнопкой не бывает.
5. **Бренд, палитра, шрифты OzoneBox.** Причина: решение владельца 30.09.2026.
6. **Нарисованный нейросетью прибор.** Только фото настоящего прибора. Причина: доверие.
7. **Стоковые «врачи», эмодзи вместо иконок.**
